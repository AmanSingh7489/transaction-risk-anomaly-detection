# Transaction Risk & Anomaly Detection Analysis

A data-driven project focused on analyzing transaction data to identify
potentially fraudulent and high-risk transaction patterns using SQL and Python.

## Project Overview

The project analyzes transaction-level data to understand patterns
associated with fraudulent and potentially suspicious transactions.

The analysis combines SQL-based exploration with Python and Pandas
to derive insights and support a basic transaction risk assessment.

## Objectives

- Analyze transaction data and identify risk patterns.
- Explore fraud rates across different transaction categories.
- Use SQL for structured transaction analysis.
- Use Python and Pandas for data exploration.
- Identify potentially unusual or high-risk transaction patterns.
- Generate data-driven recommendations for risk assessment.
